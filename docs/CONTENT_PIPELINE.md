# 批量学习内容工具（V53）

本轮建立可重复运行的本地编译流程，优先利用已经保存的资料，把内容送到知识点的学习和专项练习入口。生成无需联网、额外 AI 服务或密钥。本轮没有新增外部抓取，也没有把自动整理称为人工审定。

## 使用

在项目根目录运行：

```powershell
node tools/update_practice.cjs
```

该命令依次生成、检查生成结果是否最新、验证内容、运行隔离浏览器检查、构建 `dist/` 并检查部署包。任一步失败即停止，不继续打包成功结果。工具本身不操作 Git；当前协作按项目授权，在验证后提交推送并核对 Cloudflare。

只生成：`node tools/build_practice_pipeline.cjs`。只检查是否需要重新生成：`node tools/build_practice_pipeline.cjs --check`。源码和规则相同，输出逐字相同，没有影响重复构建的时间戳。

## 输入与输出

输入为现有可信本地数据 `app/data.js`、`app/extra.js`、`app/foundations.js`、`app/kwiziq-reference.js`，以及显式映射规则 `content/pipeline-rules.json`。不执行未知下载文件或用户提交的 JavaScript。编译器本身及所有输入均保留 SHA-256 指纹。

- `app/generated-practice.js`：离线可用的练习、稳定编号、来源信息及知识点索引。按需加载，同时包含在离线缓存与部署清单中。
- `content/pipeline-report.json`：全部 162 点覆盖、新增与原有题数量、每个被跳过候选的原因。用于维护，不把它当作学习掌握度。
- `tools/check_practice_pipeline.cjs`：核对全部生成题的来源、答案、可接受写法、例句重建和覆盖数量。

## 本轮实际结果

| 类型 | 数量 | 含义 |
|---|---:|---|
| 原有专项题 | 1,334 | 重用原题，保留选择、填空、纠错、阅读题干与解释；不计入新增 |
| 新变位题 | 11,565 | 从已获授权导入的 KwizIQ 参考表提取，明确动词、时态/语式、人称，只要求写变位部分 |
| 新例句回忆 | 289 | 按本课已有填空目标，在本课双语例句中找唯一匹配并遮住，要求复原参考原句 |

全部 162 点有原有专项题；139 点获得新增内容。其余 23 点没有强行生成新题。新增变位题主要练形式，不能替代对语境、时态选择、语用或自由表达的检测；例句回忆不表示能独立迁移。

候选跳过：116 条例句没有唯一的已知目标，2,088 行变位没有精确知识点映射，6 行含尚未支持的特殊写法，3 行为 pouvoir 命令式 n/a。报告保留候选来源，后续可以集中补规则；这些未上线候选不计为题目。

## 生成与核对规则

原有选择题保持原选项，不随意转成可能歧义的自由填空。例句只在原知识点内匹配既有填空目标，以法语字母边界匹配，要求唯一出现且填回答案能逐字重建原句。解释复用本课现有规则，不凭空生成语法解释。

变位采用显式时态和动词映射；例如过去分词配合课不会仅凭包含复合时态就被塞入普通变位题。现在时的不规则动词与规则动词按名单区分。命令式源表两列分别为形式和括号人称，单独解析；不适用项不出题。仅展开源表明确的 `(e)`、`(s)` 性数记法，不把括号原样当答案；其他不支持写法留在报告中。

来源题保留原题编号，新题用来源与目标生成稳定哈希编号。指纹变化后旧轮次安全失效，提示重新开始；已有主测验与学习进度不受影响。

## 学习流程与记录

课程库、动词页、每课讲解可进入专项页。专项页提供原规则和可展开例句。混合检测最多 4 道原题加 4 道新变位；没有新变位时最多 8 道原题。也可单练新增变位或例句回忆。

答案提交后保存，整轮完成才显示答案、解释、原例句或本地变位表链接。原有题、变位题和例句回忆分开显示结果；本轮固定开始时的重音严格/宽松设置。

进行中的轮次在 `state.batchStudy`，只保存题目编号和作答；完成记录在 `state.batchPractice`，全站最多 20 轮，重复打开结果页不重复计数。不写入原 `kps`、`attempts`、`sessions` 或调度。用户导出学习记录会包含这些字段，仓库不提交个人记录。

## 后续批量扩展

调整 `content/pipeline-rules.json` 可集中扩充准确的形式与知识点关联。添加数据源适配时，应先生成相同的题目和来源结构，再通过当前验证流程；不能仅因主题或词性相近就关联到某个具体知识点。

Tatoeba 或结构化词典的新增导入，需要另加下载缓存、来源/授权元数据、去重与词义区分；AI 批量中文整理需要单独配置服务、费用及语义校验。当前工具没有假装这两种适配已完成。重复自动生成和结构校验不能证明所有自然语言题目都无歧义；新规则需抽查样本，异常保留在候选报告。
