# 发布记录与界面约定

## V49 · 基础精讲：学懂，再验证 · 2026-11-02

- 产品优先级明确为“知识点讲解”和“独立检验学习效果”，已记录在 AGENTS.md。
- 增强 10 个已有基础知识点：定冠词、不定冠词、主语代词、être、avoir、规则 -er 现在时、ne…pas、部分冠词、主有形容词、形容词性数配合。
- 每课包含一个可检验学习目标、三个中文判断步骤、两组带推理过程的例句；共 30 个判断步骤和 20 组解析例句。
- 新增 60 道原创题：20 道选择、20 道填空、20 道整句纠错，每道均有中文原因说明；每个选择题的错误选项另有针对性反馈。题库由 1,274 题增至 1,334 题，知识点仍为 162 个。
- 课程库增加“基础精讲与学后检测”入口；精讲页及引导练习完成页可进入本课 6 题检测。
- 检测全组完成前隐藏答案、对错、掌握度变化和即时订正，不自动前进、不插入重试题；保留中途刷新恢复。
- 结果分别显示辨认、填空、纠错三类的首次作答情况，跳过标记尚未验证；重复检测明确披露见过的题数。单组答对不等于长期掌握，提示隔日再测。
- 新题也进入常规语法练习池；讲解中的常见错误表不会提前展示检测题。历史答题和跳过记录用于识别重复题。
- 281 项基础内容检查验证课程结构、题型分布、选项反馈和答案匹配，尤其验证原错误句不会被拼写容错误判为正确；98 项浏览器检查覆盖检测流程、统一反馈、恢复和结果分类。

## V48 · 错题修复站 · 2026-11-02

- 错题本新增深绿色概览：待复习、已巩固、反复出错。
- 支持中文标题和题干搜索、级别筛选、状态切换、按答错次数或最近出错排序；搜索保留光标位置，中文输入法组词期间不重建输入框。
- 答案默认折叠，查看参考答案不计为答题；每道题可重读讲解或单独再练。
- 批量复习只选当前筛选中的待复习题，每轮最多 5 题；已巩固记录仍可查看或单独重练。
- 首页显示待复习错题入口；现有掌握度与错题自动巩固规则保持一致。
- 检查手机布局、空筛选、已巩固筛选、批量题目范围及无匹配时的按钮禁用。
- 浏览器检查扩展至 66 项，并保留原有调度、数据、迁移、备份和离线升级检查。首页待复习入口会重置旧筛选，避免停留在已巩固视图。
- 用户明确要求本项目每轮验证完成后自动提交并推送 GitHub，由现有 Cloudflare 集成部署；已记录在根目录 AGENTS.md。

## V47 · 今日学习罗盘 · 2026-11-02

- 首页更新卡改为紧凑横幅，突出真正的学习入口。
- 新增“复习到期、巩固薄弱、学习下一课”路线，显示数量、可用状态和推荐理由；初学者的未学课程不会进入复习入口。
- 首页主按钮改为中文，说明新课或短练的预计用时；恢复测验时显示实际已答题数。
- 新增累计练习足迹：翻译参考句平均匹配度、已练句数、句子练习正确率和各语境标签的答题情况；可按标签返回句子页继续练习。
- 统计读取现有数据，空记录显示破折号；句子正确率按总答对数 / 总答题数加权，翻译揭晓计零分；不将这些指标称为语法掌握度或周统计。
- 答错反馈的长例句可展开，再练题保留在外；入门课程的中文讲解仍直接显示。
- 手机显示完整每日目标分母，提示消息移至底部导航上方；检查 390 和 320 像素宽度。
- 修复旧翻译练习占据句子总览的问题；按标签跳转会打开筛选页，并保留句子练习的续接入口。
- 47 项隔离浏览器检查通过，包含统计写入、备份恢复、练习续接、手机提示位置与离线更新。公网发布状态单独确认。

- quoi 改为代词；修正 part、cours、aide、ton 等错配例句，增加词义提示。
- toast 增加读屏播报，辅助文字颜色加深。
- 更新按钮等待新离线版本接管后才刷新；HTML 与资源从同一版本缓存读取。

词汇校订源为 `content/vocab/reviewed.json`。`python tools/fetch_vocab_examples.py --emit-only` 会保留校订。

## 后续更新约定

用户偏好：**每次更新都应有明确可见的 UI 变化，让人能感受到更新已经发生。**

发布授权：每轮修改并验证完成后，自动提交并推送 GitHub；用户已配置 Cloudflare 自动关联。推送后核对公网版本，不把推送完成等同于部署成功。

1. 在 `app/release.js` 更新唯一的 id、version、date、title 和实际 changes；该文件同时决定界面版本与离线缓存版本。
2. 为本次改进提供有实际用途的可见变化，例如学习入口、反馈、统计或页面排版；保留首页版本卡，说明具体变化。
3. 检查桌面和手机，保存预览，确认页面显示的是本次版本。
4. 运行相关检查和 `node tools/smoke_studio.cjs`；该浏览器检查需要 `.dev` 下的 Playwright 和 Chromium，使用隔离的测试记录。
5. `python tools/build_dist.py` 后运行 `python tools/check_deploy.py`。构建目录是可再生成的 `dist/`。
6. 发布后检查现有安装的更新提示、切换后的版本号，以及断网重载。不应把本地完成等同于公网已更新。

V46 已通过本地桌面、手机、保存失败恢复和离线版本升级检查；公网发布状态应单独确认。
